# Posyandu Web Client

This Next.js application uses Bun 1.4.4 for package installation and runtime.

## Install

```bash
bun install --frozen-lockfile
```

## Development

```bash
bun run dev
```

The development server runs at [http://localhost:3001](http://localhost:3001).

## Build and run

```bash
bun run build
bun run start
```

## Lint

```bash
bun run lint
```

Use Bun 1.4.4 in deployment environments and configure install, build, and start commands as shown above. See the [Next.js documentation](https://nextjs.org/docs) for framework details.
